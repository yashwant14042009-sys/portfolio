Q-Sentinel

Hybrid Quantum-Classical Early Disease Screening Platform

PythonFlaskNumPyscikit-learnSQLiteDocker
0.997AUC
98.1%Recall
97.9%Accuracy
  • Built a hybrid quantum-classical screening system with a REST API and web dashboard, combining a classical logistic model with a 4-qubit variational quantum classifier (data re-uploading, 3 layers) simulated exactly in NumPy, so no quantum hardware or SDK is needed.
  • Trained and benchmarked the model on the Wisconsin Breast Cancer dataset (569 samples). The hybrid advantage gate reached 0.997 AUC, 98.1% recall and 97.9% accuracy, compared with 0.995 AUC and 96.2% recall for the classical 30-feature baseline.
More details
  • Designed an “advantage gate” that routes each prediction to quantum-led, classical-led or ensemble mode, and falls back to the classical model when simulated noise exceeds 25%.
  • Used a recall-first screening threshold (0.40) and added per-feature ablation attribution to explain each prediction.
  • Developed 12+ Flask endpoints (prediction, benchmarking, retraining, history), plus a SQLite log that tracks patient risk trends and raises a drift alert if risk rises more than 10 points. Added API-key auth, input validation, unit tests and Docker deployment.
